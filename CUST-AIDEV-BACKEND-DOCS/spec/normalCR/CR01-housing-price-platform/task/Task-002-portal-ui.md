# Task-002 Unified Next.js Portal Foundation / 统一 Next.js 门户基座

## Objective / 目标
Build the shared `Next.js` portal foundation for both applications.
为两个应用构建共享的 `Next.js` 门户基座。

## Scope / 范围
- Use `Next.js App Router`.
- 使用 `Next.js App Router`。
- Implement shared navigation and layout.
- 实现共享导航和布局。
- Implement routing between and within applications.
- 实现应用之间和应用内部路由。
- Provide consistent design system using `Tailwind CSS`.
- 使用 `Tailwind CSS` 提供一致设计系统。
- Implement layout-level loading and error states.
- 实现布局层 loading 和 error 状态。
- Use Server Components and Client Components appropriately.
- 合理使用 Server Components 和 Client Components。
- Create custom hooks for shared client functionality.
- 为共享客户端能力创建 custom hooks。

## Acceptance Criteria / 验收标准
- The portal navigates between estimator and market analysis applications.
- 门户可在估值应用和市场分析应用之间导航。
- Loading and error states exist at layout level.
- 布局层具备 loading 和 error 状态。
- Shared styling and accessible components are applied consistently.
- 共享样式和可访问组件被一致应用。
