# Task-003 Property Value Estimator App / 房产估值应用

## Objective / 目标
Build App 1 with a frontend estimator experience and a Python backend.
构建应用一：带前端估值体验和 Python 后端的房产估值应用。

## Scope / 范围
- Create form for all model fields.
- 创建包含所有模型字段的表单。
- Implement client-side validation with appropriate error messages.
- 实现客户端校验和明确错误提示。
- Display predictions in table and chart format.
- 以表格和图表展示预测结果。
- Implement history of previous estimates.
- 实现历史估值记录。
- Implement comparison view for multiple properties.
- 实现多房产对比视图。
- Build Python backend for form submission handling.
- 构建处理表单提交的 Python 后端。
- Integrate Python backend with the ML model container.
- 将 Python 后端与 ML 模型容器集成。
- Implement backend validation and error handling.
- 实现后端校验和错误处理。

## Acceptance Criteria / 验收标准
- Users can submit a property and receive a prediction.
- 用户可提交房产信息并获得预测。
- Results are shown in both table and chart form.
- 结果同时以表格和图表展示。
- History and comparison views work with prior estimates.
- 历史和对比视图可使用过往估值记录。
- Python backend calls the ML model API.
- Python 后端调用 ML 模型 API。
