# Task-005 Integration, Demo, and Deployment / 集成、演示与部署

## Objective / 目标
Prepare the full system for live interview demonstration.
准备完整系统用于面试现场演示。

## Scope / 范围
- Verify model API, Python backend, Java backend, and Next.js portal startup.
- 验证模型 API、Python 后端、Java 后端和 Next.js 门户启动。
- Verify cross-service API calls.
- 验证跨服务 API 调用。
- Prepare local deployment guide.
- 准备本地部署指南。
- Validate Swagger/OpenAPI demo for model API.
- 验证模型 API 的 Swagger/OpenAPI 演示。
- Validate both applications in the portal.
- 验证门户中的两个应用。

## Acceptance Criteria / 验收标准
- All services can start locally.
- 所有服务可在本地启动。
- Both application backends can call the model API.
- 两个应用后端均可调用模型 API。
- The portal can demonstrate the estimator and market analysis flows.
- 门户可演示估值和市场分析流程。
