# Task-004 Property Market Analysis App / 房产市场分析应用

## Objective / 目标
Build App 2 with an interactive market analysis frontend and a Java backend.
构建应用二：带交互式市场分析前端和 Java 后端的房产市场分析应用。

## Scope / 范围
- Create interactive dashboard with market visualizations.
- 创建带市场可视化的交互式仪表盘。
- Implement filters for property segments.
- 实现房产分段筛选。
- Build what-if analysis using the ML model.
- 使用 ML 模型构建 what-if 分析。
- Provide CSV and PDF export options.
- 提供 CSV 和 PDF 导出。
- Create responsive data tables with sorting and filtering.
- 创建支持排序和过滤的响应式数据表。
- Build Java 21 + Spring Boot 3.4.4 REST APIs.
- 构建 Java 21 + Spring Boot 3.4.4 REST API。
- Generate aggregate statistics from the housing dataset.
- 基于房价数据集生成聚合统计。
- Integrate Java backend with the ML model container.
- 将 Java 后端与 ML 模型容器集成。
- Implement caching for performance optimization.
- 实现缓存优化。

## Acceptance Criteria / 验收标准
- Dashboard visualizations render market analysis data.
- 仪表盘可视化可展示市场分析数据。
- Segment filters change the analysis results.
- 分段筛选可改变分析结果。
- What-if analysis calls the ML model API.
- what-if 分析调用 ML 模型 API。
- CSV and PDF exports work.
- CSV 和 PDF 导出可用。
- Java backend exposes market analysis REST APIs.
- Java 后端暴露市场分析 REST API。
- Caching is implemented for aggregate or analysis responses.
- 聚合或分析响应实现缓存。
